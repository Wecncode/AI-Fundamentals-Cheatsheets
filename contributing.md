# Contributing to AI Fundamentals Cheatsheets

First off, thank you for considering contributing to this repository! This project grows and improves thanks to the collective knowledge of the open-source community.

Whether you are fixing a typo, correcting a mathematical formula, or adding an entirely new cheatsheet on an emerging AI topic, your help is appreciated.

## Types of Contributions

You can contribute to this repository in several ways:
<ul>
   <li> Adding New Cheatsheets: Have expertise in a topic we haven't covered yet (e.g., Reinforcement Learning, MLOps, Computer Vision)? You can add new .md files to the appropriate directories.

   <li> Updating Content: AI moves fast. If you see outdated information, especially in the Generative AI or LLM sections, please update it.

   <li> Fixing Errors: If you spot a factual inaccuracy, a broken link, or a typo, feel free to submit a fix.
</ul>


## How to Contribute

To contribute your changes, please follow this standard GitHub workflow:

### 1. Fork and Clone

Fork this repository to your own GitHub account.

Clone your fork to your local machine:
git clone https://github.com/YOUR-USERNAME/ai-fundamentals-cheatsheets.git

### 2. Create a Branch

Create a new branch for your specific feature or fix. Use a descriptive name:
git checkout -b update-svm-formula or git checkout -b add-mlops-cheatsheet

### 3. Make Your Changes

Make your edits or add new files.

Ensure any mathematical formulas or code snippets are technically accurate.

### 4. Commit and Push

Commit your changes with a clear, concise commit message explaining what you changed and why:
git commit -m "Update SVM formula to correct indexing error"
Push the branch to your fork:
git push origin your-branch-name

### 5. Submit a Pull Request (PR)

Open a Pull Request from your fork against the main branch of this repository.

In the PR description, briefly explain the changes you made. If your PR resolves an open issue, link to it (e.g., "Fixes #12").

## Reporting Issues

If you don't have the time to submit a Pull Request, you can still contribute by reporting issues!

Navigate to the Issues tab.

Clearly describe the problem, including the file name and the specific section where the error occurs.

For feature requests, explain what topic you think should be added and why it would be beneficial to the repository.

*Thank you for helping make this a better resource for everyone! 🩶*
